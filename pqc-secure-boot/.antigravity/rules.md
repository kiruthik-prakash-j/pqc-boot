# System Constraints & Global Rules

## Overview
Project guidelines for Post-Quantum Cryptography (PQC) Secure Boot project across embedded C/C++, QEMU emulation, and Docusaurus documentation workspace.

## Constraints
- **C/C++ & Firmware**: Standard C11 / C++17 for embedded targets (RISC-V virt, ARM Cortex-M, ARM Cortex-A).
- **Emulation**: Target QEMU platforms for testing and verification.
- **Documentation**: Maintain comprehensive logs, research, and implementation thesis in `docs-site/`.
